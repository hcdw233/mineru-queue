统计口径与状态说明

页面每分钟刷新。总完成量按当前任务表中每篇任务的最新状态统计，同一篇重跑成功只计一次。吞吐按任务完成时间统计实际成功篇数，重跑成功会再次计入。滚动 60 分钟与整点小时是不同时间范围。单篇平均耗时从开始处理算到 zip 下载完成，缺少开始时间的旧记录仍计入成功篇数。

进度文件只追加，一行是 任务主键   状态   下载完成时间   开始时间。旧行可以只有前三列。MinerU 还在 queued 或 running 时不会写这一行。

  • success：任务 completed，zip 已下载并解压。
  • failed：MinerU 返回 failed，或 PDF 缺失、上传、协议、下载、解压出错。
  • partial：MinerU 返回 partial。已尽量保存产物，记入「其他」，重跑时会再次执行。
  • canceled：MinerU 返回 canceled。记入「其他」。
  • timeout：轮询次数用尽。远端任务不会被取消，记入「其他」，重跑会重新提交。
